Swift Ship Tracker

#Project Overview

Swift Ship Tracker is a Salesforce-based parcel management and tracking system developed to manage parcel, delivery, sender, and receiver information in a centralized platform.

The system allows users to maintain shipment details, track parcel information using a Parcel ID, and retrieve relevant details through Salesforce automation and Agentforce.

#Key Features

- Parcel, Delivery, Sender, and Receiver management
- Custom fields and relationships between objects
- Parcel tracking using Parcel ID
- Automated parcel detail retrieval using Salesforce Flow
- Permission Set for controlled access
- Prompt Builder for retrieving parcel information
- Einstein Agent / Agentforce for conversational parcel tracking

#Technology Used

- Salesforce
- Custom Objects & Fields
- Object Relationships
- Salesforce Flow
- Permission Sets
